## What the project does

**LearningAppForKids** is an Android learning app for kids built as the P3 Activity & Quiz for ITE 393. 

This version focuses on **Animal Sounds** - an interactive module where kids can tap on animal cards/images to hear the animal's sound and learn its name. It was built entirely with **Jetpack Compose** as a modern Android UI learning exercise.

Features in this build:
- Home Page with learning categories
- Animal Sound Page with image + audio playback
- Simple, kid-friendly UI with large tap targets

## Why the project is useful

1.  **For Students:** A reference implementation for ITE 393 students learning how to build a basic Jetpack Compose app, handle `res/drawable` and `res/raw` assets, and implement simple audio playback.
2.  **For Kids:** A lightweight educational tool to help kids associate animals with their sounds and images.
3.  **For Beginners:** Shows a clean, minimal structure for a kids learning app without complex architecture - easy to fork for other topics (colors, numbers, alphabet).

## How users can get started with the project

This project is for educational / reference purposes only as it is archived.

**Prerequisites:**
- Android Studio Ladybug or newer
- Kotlin 1.9+
- Android SDK 24+

**Setup:**

1.  Clone the repository:
    ```bash
    git clone https://github.com/fpaulpalis/LearningAppfForKids.git
    ```
2.  Open in Android Studio.
3.  Sync Gradle and let dependencies download.
4.  **Assets:** Images and sounds are already included in `res/drawable` & `res/raw`. If files are missing, you can download them from my [Google Drive](https://drive.google.com/drive/folders/1H3TCedKK3aU0avItKlYElKQ2yBri4lrY?usp=sharing).
    > Credits: images and sounds are copied from [orkuneyb/animal_sounds_flutter](https://github.com/orkuneyb/animal_sounds_flutter)

5.  Run on an emulator or physical device.
